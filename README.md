# ASTEROIDS P2P

Atari「Asteroids」風のブラウザゲームです。1〜4人で遊べて、小惑星を壊した得点を競います。相手プレイヤーも撃てます。
複数人で遊ぶときは、ブラウザ同士が WebRTC で直接つながります。ゲーム用のサーバーは使いません。

## 遊び方

- **ソロ**：残機3で、原作のようにスコアを伸ばします（ハイスコアはブラウザに保存）
- **画面**：自機が常に画面の中央で上向きになり、周りの世界が回転・移動して見えます。フィールドは画面の4倍の広さで、端は反対側につながります。弾は画面の端まで届きます。対戦中は右下のレーダーで相手の位置が分かります
- **対戦（2〜4人）**：制限時間（1分・3分・5分から選択）の間に取った得点で競います。撃破されても数秒で復活し、復活直後は無敵です

| 対象 | 得点 |
|---|---|
| 小惑星 大 / 中 / 小 | 20 / 50 / 100 |
| UFO 大 / 小 | 200 / 1000 |
| 他プレイヤー撃破 | 200 |

### 操作

| | 回転 | 推進 | 発射 |
|---|---|---|---|
| PC | ← → / A D | ↑ / W | Space |
| スマホ | ◀ ▶ | ▲ | ●（長押しで連射ホールド） |

### 対戦の始め方

**QRコードで参加（おすすめ）**
1. ホストが「部屋を作る」を押し、空き枠で「招待コードを作成」を押す
2. ゲストはスマホのカメラで、ホストの画面のQRコードを読み取る（ページが開き、返答用のQRが自動で出ます）
3. ホストが「返答QRを読み取る」を押し、ゲストの画面のQRをカメラで読み取る（ゲストの人数分くり返す）
4. ホストが「ゲーム開始」を押す

**コードで参加（カメラが使えないとき）**
- QRの代わりに、招待コード（または参加URL）と返答コードを LINE などで送り合って、それぞれ貼り付けます

接続画面には、接続の状態と「LAN / グローバル」のアドレス候補の数が表示されます。つながらないときは、この表示で原因の見当がつきます。
- グローバルが 0：STUNが使えていません。STUNをONにするか、同じWi-Fiで試してください
- 両方グローバルが1以上なのに失敗：回線（NAT）の組み合わせが原因の可能性があります。片方をテザリングや別の回線に変えて試してください

### 通信についての注意

- インターネット越しに遊ぶときは「STUNサーバーを使う」をONにしてください（初期値ON）。公開STUN（Google）は自分のアドレスを調べるためだけに使い、ゲームのデータは中継しません
- 回線の種類（対称型NATなど）によっては接続できないことがあります。中継サーバー（TURN）は使いません
- ホストのタブが裏に回るとゲームが止まります。ホストはゲーム中、画面を表示したままにしてください

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト
npm run build    # dist/ に静的ファイルを出力
```

## 公開（GitHub Pages）

`main` ブランチにプッシュすると `.github/workflows/deploy.yml` が動き、テストとビルドのあとに GitHub Pages へデプロイします。
最初の1回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

このページには `noindex` を付けてあり、検索エンジンには載りにくくなっています。ただし GitHub Pages には閲覧者を制限する機能がないため、URLを知っていれば誰でも開けます。URLを推測されにくくするには、リポジトリ名を推測されにくいものに変えてください（URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` になります）。

設計の詳細は [docs/PLAN.md](docs/PLAN.md) にあります。
