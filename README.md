# ASTEROIDS P2P

Atari「Asteroids」風のブラウザゲームです。1〜4人で遊べて、小惑星を壊した得点を競います。相手プレイヤーも撃てます。
複数人で遊ぶときは、ブラウザ同士が WebRTC で直接つながります。ゲーム用のサーバーは使いません。

## 遊び方

- **ソロ**：残機3で、原作のようにスコアを伸ばします（ハイスコアはブラウザに保存）
- **対戦（2〜4人）**：制限時間（1/2/3/5分）の間に取った得点で競います。撃破されても数秒で復活し、復活直後は無敵です

| 対象 | 得点 |
|---|---|
| 小惑星 大 / 中 / 小 | 20 / 50 / 100 |
| UFO 大 / 小 | 200 / 1000 |
| 他プレイヤー撃破 | 200 |

### 操作

| | 回転 | 推進 | 発射 | ハイパースペース |
|---|---|---|---|---|
| PC | ← → / A D | ↑ / W | Space | ↓ / S |
| スマホ | ◀ ▶ | ▲ | ● | HYP |

### 対戦の始め方（手動コード交換）

1. ホストが「部屋を作る」を押し、空き枠で「招待コードを作成」を押す
2. 招待コードを LINE などでゲストに送る
3. ゲストは「部屋に参加」で招待コードを貼り付け、「返答コードを作成」を押してホストに送り返す
4. ホストが返答コードを貼り付けて「接続」を押す（ゲストの人数分くり返す）
5. ホストが「ゲーム開始」を押す

### 通信についての注意

- インターネット越しに遊ぶときは「STUNサーバーを使う」をONにしてください（初期値ON）。公開STUN（Google）は自分のアドレスを調べるためだけに使い、ゲームのデータは中継しません
- 回線の種類（対称型NATなど）によっては接続できないことがあります。中継サーバー（TURN）は使いません
- ホストのタブが裏に回るとゲームが止まります。ホストはゲーム中、画面を表示したままにしてください

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト
npm run build    # dist/ に静的ファイルを出力
```

## 公開（GitHub Pages）

`main` ブランチにプッシュすると `.github/workflows/deploy.yml` が動き、テストとビルドのあとに GitHub Pages へデプロイします。
最初の1回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

設計の詳細は [docs/PLAN.md](docs/PLAN.md) にあります。
